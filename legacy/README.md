# Legacy plugins

Older Soft Body plugins, kept here for reference and for anyone who wants to build them.
Development continues in **Soft Body Suite 3** (`../SoftBodySuite/`).

## Classic Soft Body Suite (v2)

`SoftBodySuite-v2/` is the source of the classic suite (Wobble, Jell-o, Squish and clothes
follow in one plugin, `SoftBodySuite.dll`). The ready-made plugin is in the
[v2.0.1 Final classic edition](https://github.com/alienware377/VNyan-SoftBody-Suite/releases/tag/v2.0.1-final-classic)
release. Don't install it next to Soft Body Suite 3: VNyan would run both and move the body
twice.

## v1 studios

Source of the four separate plugins from v1.x: Squish Studio, Wobble Studio, Jello Studio
and SoftBody Studio. Since v2.0.0 the first three are merged into the suite. The ready-made
v1 plugins are in the
[v1.2.0 release](https://github.com/alienware377/VNyan-SoftBody-Suite/releases/tag/v1.2.0).
Don't install them next to the suite either.

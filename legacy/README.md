# Legacy v1 studios

Source of the four separate plugins from v1.x — Squish Studio, Wobble Studio, Jello Studio
and SoftBody Studio. Since v2.0.0 the first three are merged into the single
**Soft Body Suite** plugin (`../SoftBodySuite/`), which is where development continues.

They're kept here for reference and for anyone who wants to build the old plugins. The
ready-made v1 plugins are in the
[v1.2.0 release](https://github.com/alienware377/VNyan-SoftBody-Suite/releases/tag/v1.2.0).
Don't install them next to the suite — VNyan would run both and move the body twice.
